# Pathfinder 1E — Core Rulebook player catalog

Curated **mechanics-only** data for the PF1e sheet. Not a copy of the Core Rulebook.

| File | Contents |
| --- | --- |
| `pack.json` | Manifest and which review batches have landed |
| `classes.json` | Class **progression tags** (HD, BAB, saves). Batch 1: Fighter, Wizard. Batch 2 reused those HD sizes for the HP dialog. |

See [`docs/pf1e-crb-pack-design.md`](../../../docs/pf1e-crb-pack-design.md) for the review process, landed batches, and **annotated upcoming batches** (next is size tables).

**License:** app is MIT. This folder contains numeric game-mechanic metadata (formulas live in the engine). No Product Identity, no class flavor, no spell text. Do not scrape third-party SRDs into this tree.
